# Security

`oos` reads Terraform state, which can contain secrets such as database passwords, and uses your AWS credentials. Reports of anything that could expose state contents or credentials, or make `oos` change infrastructure, are especially welcome.

## Reporting a vulnerability

Please report security problems privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

You will get a reply within a few days. Once a fix is released, the advisory is published with credit unless you prefer otherwise.

## Supported versions

Only the latest release receives fixes.
